# online_shoppers_intention
# Прогнозирование покупки в интернет-магазине

Проект по машинному обучению для предсказания того, завершится ли пользовательская сессия на сайте интернет-магазина покупкой.

**Предметная область:** бизнес / маркетинг

## Описание проекта

Цель проекта — построить и исследовать модель машинного обучения, которая по характеристикам пользовательской сессии предсказывает значение целевой переменной `Revenue`:

- `True` / `1` — пользователь совершил покупку;
- `False` / `0` — пользователь не совершил покупку.

Это задача **бинарной классификации**.

Такая модель может быть полезна интернет-магазину для:

- выделения сессий с высокой вероятностью покупки;
- персонализации интерфейса сайта;
- более точного таргетинга рекламы, акций и скидок;
- анализа факторов, влияющих на конверсию.

## Данные

В проекте используется датасет **Online Shoppers Purchasing Intention Dataset** из UCI Machine Learning Repository.

Каждая строка датасета описывает одну пользовательскую сессию на сайте интернет-магазина.

Основные признаки:

- `Administrative`, `Administrative_Duration` — количество и длительность посещения административных страниц;
- `Informational`, `Informational_Duration` — количество и длительность посещения информационных страниц;
- `ProductRelated`, `ProductRelated_Duration` — количество и длительность посещения товарных страниц;
- `BounceRates` — показатель отказов;
- `ExitRates` — показатель выходов со страницы;
- `PageValues` — ценность страницы для покупки;
- `SpecialDay` — близость сессии к специальному дню или празднику;
- `Month` — месяц сессии;
- `OperatingSystems`, `Browser`, `Region`, `TrafficType` — технические и поведенческие характеристики;
- `VisitorType` — тип посетителя;
- `Weekend` — была ли сессия в выходной день;
- `Revenue` — целевая переменная.
